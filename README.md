# Business Card
A simple, static and styled business card web page built with HTML and CSS.

## Preview
![Business Card](https://github.com/user-attachments/assets/e29df0db-1072-450c-968b-f50877caefc9)

## Description
This project is a static business card that displays a profile image, name and professional title. The card features a clean, centered design with custom styling and color scheme.

## Technologies
- HTML5
- CSS3

## Features
- Clean, centered layout with a styled card container
- Profile image with border styling
- Centered text alignment for name and title
- Responsive centering (both horizontal and vertical)
- Custom color scheme with pink tones
- Rounded corners and bordered card design
- Horizontal divider line between sections
- Custom typography using Calibri font

## Installation & Usage
To view this project locally:

1. Clone the repository:
   ```
   git clone https://github.com/vanessapopa/Business-Card.git
   ```

2. Navigate to the project directory:
   ```
   cd Business-Card
   ```

3. Open `index.html` in your web browser
